🧪 Teste do Kanban de Subtarefas

Este arquivo contém os passos para testar se o Kanban de subtarefas está funcionando corretamente.

1. Verificar Console do Navegador
Abra o console do navegador (F12) e verifique se não há erros JavaScript.
  1. Pressione F12 ou Ctrl+Shift+I
  2. Vá para a aba Console
  3. Verifique se há mensagens de erro em vermelho
  4. Procure por logs do Kanban (começando com "===")

✅ Resultado Esperado:

  • Nenhum erro JavaScript no console
  • Logs do Kanban aparecendo corretamente
  • Mensagens como "=== SUBTASK KANBAN RENDERIZADO ==="
2. Testar Criação de Subtarefas
Verificar se é possível criar novas subtarefas no Kanban.
  1. Navegue até "Minhas Atividades"
  2. Expanda uma atividade que tenha subtarefas
  3. Ative o modo Kanban
  4. Clique em "Nova Subtarefa"
  5. Digite um título e clique em "Adicionar"

✅ Resultado Esperado:

  • Botão "Nova Subtarefa" visível
  • Campo de input aparece ao clicar
  • Subtarefa é criada e aparece na coluna "A Fazer"
  • Toast de sucesso é exibido
3. Testar Drag and Drop Entre Colunas
Verificar se as subtarefas podem ser arrastadas entre as colunas do Kanban.
  1. No modo Kanban, identifique uma subtarefa na coluna "A Fazer"
  2. Passe o mouse sobre a subtarefa (deve aparecer cursor de arrasto)
  3. Clique e segure na subtarefa
  4. Arraste para a coluna "Em Progresso"
  5. Solte a subtarefa

✅ Resultado Esperado:

  • Cursor de arrasto aparece ao passar o mouse
  • Subtarefa pode ser arrastada
  • Subtarefa muda para a coluna de destino
  • Status é atualizado automaticamente
  • Toast de confirmação é exibido
4. Verificar Persistência das Mudanças
Verificar se as mudanças no Kanban são salvas e persistem após recarregar a página.
  1. Mova algumas subtarefas entre colunas
  2. Recarregue a página (F5)
  3. Navegue novamente para a atividade
  4. Ative o modo Kanban

✅ Resultado Esperado:

  • Subtarefas permanecem nas colunas corretas
  • Status das subtarefas é mantido
  • Contadores das colunas estão corretos
5. Verificar Logs do Console
Durante os testes, verifique os logs no console para identificar possíveis problemas.
  1. Mantenha o console aberto durante os testes
  2. Procure por logs específicos do Kanban
  3. Verifique se há erros ou warnings

✅ Logs Esperados:

=== SUBTASK KANBAN RENDERIZADO === === SINCRONIZANDO ESTADO INTERNO === === GET SUBTASKS BY COLUMN === === DRAG START === === DRAG END === === ATUALIZANDO NO BANCO === === ATUALIZANDO ESTADO INTERNO === ✅ onSubtasksChange executado com sucesso
6. Problemas Comuns e Soluções
Lista de problemas que podem ocorrer e como resolvê-los.

🚨 Problemas Identificados:

  • Subtarefas não aparecem: Verificar se o mapeamento de status está correto
  • Drag and drop não funciona: Verificar se os IDs são únicos e válidos
  • Mudanças não persistem: Verificar se onSubtasksChange está sendo chamado
  • Múltiplas subtarefas na mesma coluna: Verificar lógica de filtragem
7. Checklist de Verificação
Lista de verificação para confirmar que tudo está funcionando.

✅ Checklist:

  • Console sem erros JavaScript
  • Kanban renderiza corretamente
  • Subtarefas aparecem nas colunas corretas
  • É possível criar novas subtarefas
  • Drag and drop funciona entre colunas
  • Mudanças são salvas no banco
  • Estado persiste após recarregar
  • Contadores das colunas estão corretos
  • Logs aparecem no console
  • Toast notifications funcionam
8. Comandos de Debug
Comandos úteis para debug no console do navegador.

🔧 Comandos Úteis:

// Verificar se o componente está renderizado document.querySelector('[data-testid="subtask-kanban"]') // Verificar estado das subtarefas console.log('Subtarefas:', window.subtasks) // Forçar re-render window.location.reload() // Verificar erros de rede // Aba Network no DevTools
