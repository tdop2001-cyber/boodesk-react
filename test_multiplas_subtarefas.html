🧪 Teste - Múltiplas Subtarefas por Coluna

Este arquivo contém os passos para testar se é possível criar e exibir múltiplas subtarefas na mesma coluna do Kanban.

1. Verificar Problema Atual
Identifiquei que você consegue alternar subtarefas entre colunas, mas não consegue inserir mais de uma subtarefa por coluna.

🔍 Análise do Problema:

  • ✅ Drag and Drop funcionando - Subtarefas podem ser movidas entre colunas
  • ❌ Criação limitada - Apenas uma subtarefa por coluna
  • ⚠️ Possível causa - Lógica de filtragem ou restrição na criação
2. Testar Criação de Múltiplas Subtarefas
Siga estes passos para testar se é possível criar múltiplas subtarefas na mesma coluna.
  1. Abra o console do navegador (F12)
  2. Navegue para "Minhas Atividades"
  3. Expanda uma atividade com subtarefas
  4. Ative o modo Kanban
  5. Clique em "Nova Subtarefa"
  6. Digite um título (ex: "Teste 1") e clique em "Adicionar"
  7. Clique novamente em "Nova Subtarefa"
  8. Digite outro título (ex: "Teste 2") e clique em "Adicionar"
  9. Verifique se ambas aparecem na coluna "A Fazer"

✅ Resultado Esperado:

  • Primeira subtarefa criada com sucesso
  • Segunda subtarefa criada com sucesso
  • Ambas aparecem na coluna "A Fazer"
  • Contador da coluna mostra "2"
  • Toast de sucesso para cada criação
3. Verificar Logs do Console
Durante o teste, monitore os logs no console para identificar possíveis problemas.
  1. Mantenha o console aberto durante todo o teste
  2. Procure por logs relacionados à criação de subtarefas
  3. Verifique se há erros ou warnings
  4. Observe os logs de filtragem por coluna

✅ Logs Esperados:

=== SUBTASK KANBAN RENDERIZADO === === SINCRONIZANDO ESTADO INTERNO === === GET SUBTASKS BY COLUMN === Coluna solicitada: todo Subtarefas filtradas: [2 items] Quantidade filtrada: 2 IDs filtrados: ["id1", "id2"]
4. Verificar Banco de Dados
Confirme se as subtarefas estão sendo salvas corretamente no banco de dados.
  1. Verifique a aba Network no DevTools
  2. Procure por requisições de criação de subtarefas
  3. Confirme se retornam status 200/201
  4. Verifique se os IDs são únicos e válidos

✅ Resultado Esperado:

  • Requisições POST para criar subtarefas
  • Status de resposta 200/201
  • IDs únicos retornados para cada subtarefa
  • Dados corretos salvos no banco
5. Testar Movimentação Entre Colunas
Após criar múltiplas subtarefas, teste se elas podem ser movidas entre colunas.
  1. Mova uma subtarefa da coluna "A Fazer" para "Em Progresso"
  2. Mova outra subtarefa para "Concluído"
  3. Verifique se os contadores das colunas são atualizados
  4. Confirme se as mudanças persistem após recarregar

✅ Resultado Esperado:

  • Subtarefas podem ser movidas entre colunas
  • Contadores das colunas são atualizados corretamente
  • Status é atualizado no banco de dados
  • Mudanças persistem após recarregar a página
6. Possíveis Causas do Problema
Lista de possíveis causas para o problema de não conseguir criar múltiplas subtarefas por coluna.

🚨 Possíveis Causas:

  • Restrição no banco de dados - Limite de uma subtarefa por coluna
  • Lógica de filtragem incorreta - Função getSubtasksByColumn com problema
  • Estado interno não atualizado - Problema na sincronização
  • Função onSubtasksChange - Não está propagando mudanças
  • IDs duplicados - Conflito na geração de IDs

Lista de verificação para confirmar que o problema foi resolvido.
