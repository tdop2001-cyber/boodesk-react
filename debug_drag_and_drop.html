🐛 Debug - Drag and Drop de Subtarefas

Este arquivo contém instruções para debug do problema de drag and drop.

🚨 Problema Reportado
Problema: "SEGUEN AO FUNCIONANDO ESTOU TENTANDO ENVIAR A SUBSTASK DE A FAZER PARA EM PROGRESSO MAS ELE NAO TROCAM"

🔍 Análise do Problema:

  • Drag and Drop não funciona - Subtarefas não podem ser movidas entre colunas
  • Especificamente: Da coluna "A Fazer" para "Em Progresso"
  • Estado não atualiza - Mudanças não são aplicadas
🧪 Teste de Debug Passo a Passo
Siga estes passos para identificar exatamente onde está o problema:
  1. Recarregue a página para aplicar as correções
  2. Abra o console do navegador (F12)
  3. Navegue para "Minhas Atividades"
  4. Expanda uma atividade com subtarefas
  5. Ative o modo Kanban
  6. Execute os comandos de debug no console
  7. Tente mover uma subtarefa e observe os logs

🎯 Teste Específico de Drag and Drop:

  1. Identifique uma subtarefa na coluna "A Fazer"
  2. Clique e segure na subtarefa (deve aparecer overlay)
  3. Arraste para a coluna "Em Progresso"
  4. Solte na nova coluna
  5. Observe o console para logs de debug
🔧 Comandos de Debug no Console
Execute estes comandos no console para verificar o estado:

📝 Comandos de Debug:

// 1. Verificar estado das subtarefas console.log('=== VERIFICAÇÃO INICIAL ==='); console.log('Subtarefas internas:', window.internalSubtasks); console.log('Total de subtarefas:', window.internalSubtasks?.length || 0); // 2. Verificar filtragem por coluna console.log('=== VERIFICAÇÃO DE COLUNAS ==='); console.log('Coluna A Fazer:', window.getSubtasksByColumn && window.getSubtasksByColumn('todo')); console.log('Coluna Em Progresso:', window.getSubtasksByColumn && window.getSubtasksByColumn('in_progress')); console.log('Coluna Concluído:', window.getSubtasksByColumn && window.getSubtasksByColumn('completed')); // 3. Verificar se há subtarefas para mover const todoSubtasks = window.getSubtasksByColumn && window.getSubtasksByColumn('todo'); if (todoSubtasks && todoSubtasks.length > 0) { console.log('✅ Há subtarefas na coluna "A Fazer" para mover'); console.log('Primeira subtarefa:', todoSubtasks[0]); } else { console.log('❌ Nenhuma subtarefa na coluna "A Fazer"'); } // 4. Verificar configuração dos sensores console.log('=== VERIFICAÇÃO DE SENSORES ==='); console.log('Sensores configurados:', window.sensors); console.log('PointerSensor:', window.PointerSensor); console.log('MouseSensor:', window.MouseSensor); // 5. Verificar funções de drag and drop console.log('=== VERIFICAÇÃO DE FUNÇÕES ==='); console.log('handleDragStart disponível:', typeof window.handleDragStart); console.log('handleDragEnd disponível:', typeof window.handleDragEnd); console.log('setInternalSubtasks disponível:', typeof window.setInternalSubtasks); // 6. Verificar se há erros no console console.log('=== VERIFICAÇÃO DE ERROS ==='); console.log('Verifique se há erros em vermelho no console');

🚨 Possíveis Causas do Problema
Com base nos logs, identifique qual destes problemas está ocorrendo:

🔍 Diagnóstico por Sintomas:

1. Nenhum log aparece ao clicar:
  • Problema: Listeners não estão sendo aplicados
  • Solução: Verificar configuração do useSortable
2. Logs aparecem mas drag não inicia:
  • Problema: Sensores muito restritivos
  • Solução: Ajustar activationConstraint
3. Drag inicia mas não termina:
  • Problema: handleDragEnd não está sendo chamado
  • Solução: Verificar configuração do DndContext
4. Drag termina mas estado não atualiza:
  • Problema: setInternalSubtasks não funciona
  • Solução: Verificar lógica de atualização
📋 Checklist de Verificação
Use este checklist para confirmar que identificou o problema:

✅ Checklist de Debug:

  • Console aberto e limpo
  • Modo Kanban ativado
  • Comandos de debug executados
  • Logs de mouse down aparecem
  • Logs de drag start aparecem
  • Logs de drag end aparecem
  • Estado é atualizado
  • Problema específico identificado
